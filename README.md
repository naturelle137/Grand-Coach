# Grand-Coach

Skat-Trainer für PC (Linux und Windows 11): vollständiges Skat nach
Internationaler Skatordnung gegen zwei Computergegner. Dazu kommt ein
abschaltbarer Live-Coach, der den **Denkweg** erklärt, nicht nur den besten Zug.
Außerdem gibt es eine Kartenzählhilfe und einen Quiz-Modus sowie einen offenen
Modus, um das Hineinversetzen in die Gegner zu üben.

Status: Projektgrundlage, noch kein Code. Ziele und Entscheidungen stehen in
[docs/vision.md](docs/vision.md) und [docs/decisions.md](docs/decisions.md).
