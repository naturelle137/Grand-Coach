# Third-party files and libraries

Every third-party file (graphic, font, sound, copied code) and every runtime
dependency with a notable licence is recorded here **before** it enters the
repository.

Allowed are licences compatible with EUPL-1.2 (code) or CC BY-SA 4.0
(content). For code, e.g. MIT, Apache-2.0, BSD, Zlib, MPL-2.0 and the licences
listed in the EUPL appendix. For content: public domain, CC0, CC BY, CC BY-SA,
OFL (fonts). Not allowed: NC and ND licences, files of unclear origin.

Rust dependencies are listed in their own table below, checked by hand
against `cargo metadata`; an automated licence check is still to be set up.

| File / library | Source (URL) | Author | Licence | Changes |
|----------------|--------------|--------|---------|---------|
| Fonts embedded by egui (`epaint_default_fonts` 0.37): Ubuntu-Light, Hack, Noto Emoji, emoji-icon-font, egui-icons | <https://crates.io/crates/epaint_default_fonts> | Canonical (Ubuntu); Source Foundry (Hack); Google (Noto Emoji); John Slegers (emoji-icon-font) | Ubuntu Font Licence 1.0; MIT with Bitstream Vera licence (Hack); OFL-1.1 (Noto Emoji); MIT (emoji-icon-font and its subset egui-icons) | none; compiled into `grand-coach` via the `default_fonts` feature, not stored in the repository |

The card faces in `assets/cards/` and the texts in `assets/i18n/` are our
own work (generated by `tools/cardgen` and written for this project), not
third-party files.

macOS and Windows platform crates). Checked with `cargo metadata` on
2026-10-29: all are under permissive licences (MIT, Apache-2.0, BSD-2/3,
Zlib, ISC, BSL-1.0, Unicode-3.0, Unlicense, 0BSD) or offer one of them as
an alternative; no copyleft-only and no NC/ND licence.
