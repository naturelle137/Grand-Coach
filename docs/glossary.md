# Glossary

German Skat terms used in code and docs, with their English meaning.
Skat terms stay German in identifiers and texts (D-16).

| German | English |
|--------|---------|
| Skat | the two face-down cards; also the game itself |
| Reizen / Reizwert | bidding / bid value |
| Grundwert / Spielwert | base value / game value |
| Sagen / Hören (Halten) / Passen | bid / hold / pass |
| Vorhand / Mittelhand / Hinterhand | fore hand / middle hand / rear hand |
| Geber | dealer |
| Alleinspieler | declarer |
| Gegenspieler | defenders |
| Drücken | discarding two cards into the Skat |
| Farbspiel / Grand / Null | suit game / jacks-only trump game / no-trick game |
| Hand | played without picking up the Skat |
| Ouvert | open game, declarer's cards face up |
| Schneider / Schwarz | ≤ 30 card points / no trick for one party |
| Spitzen (mit/ohne) | matadors (with/without) |
| Überreizt | overbid (game value below bid) |
| Kontra / Re | double / redouble |
| Stich | trick |
| Trumpf | trump |
| Bedienen | follow suit |
| Abwerfen / Schmieren | discard / throw high-value cards to partner |
| Fehlfarbe | side suit (non-trump suit) |
| Frei / blank | void in a suit / singleton card |
| Augen | card points (120 in total) |
| Einpassen | all pass, hand is redealt |
| Bube / Dame / König / Ass / Zehn | Jack / Queen / King / Ace / Ten |
| Kreuz / Pik / Herz / Karo | clubs / spades / hearts / diamonds |
| Eichel / Grün / Rot / Schellen | acorns / leaves / hearts / bells (German deck) |
| Unter / Ober / Daus | Jack / Queen / Ace (German deck) |
| Altenburger Bild | standard German-suited card design |
| Liste / Serie | score sheet / series of games |
| Seeger-Fabian | tournament scoring system |
| ISkO | International Skat Rules (Internationale Skatordnung) |
